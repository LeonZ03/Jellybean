# 糖豆 Jellybean 0.2

Windows 11，x64。完整解压后双击 **Jellybean.exe**，保留旁边的文件和 Assets 文件夹。

- 单击摸摸，双击开启逗猫棒；再双击或按 Esc 结束。
- 拖动时保持现有姿势，松手后有落地缓冲。拖到窗沿会停住，窗口移动时跟随，关闭或最小化后落下。
- 滚轮调整大小；设置里的大小滑块会即时生效。右键可以选动作、切角度、随机跳窗、探头、隐藏和退出。
- 趴在窗口上时，尾巴会垂进窗口。久未互动时，糖豆会用气泡请求陪玩。
- 托盘双击打开设置，可选登录自启、游戏时收起和提醒。办公、浏览器与视频全屏继续显示。
- 找不到糖豆时，再次双击 EXE，或从托盘选「把糖豆叫回来」。

跳窗需要附近有留出头顶空间的窗口；探头需要先站在窗口上。

已开启自启时，从新目录运行一次会自动更新启动位置。
