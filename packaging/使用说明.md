# 糖豆 Jellybean 0.5.1

Windows 11，x64。在当前目录双击 **Jellybean.exe**，保留旁边的文件和 Assets 文件夹。

从旧版更新时，先从托盘退出旧版，再运行新目录里的 Jellybean.exe。原有设置会自动读取。

各个动作与视角已统一为 50 档原质感毛色。

- 单击摸摸，双击开启逗猫棒；糖豆会观察、潜行，再快速扑出。再双击或按 Esc 结束。
- 拎起拖动时，身体随加速和刹停轻摆，匀速时自然回垂。低处放下直接站稳，高处落下才屈腿缓冲。拖到窗沿会停住，窗口移动时跟随，关闭或最小化后落下。
- 滚轮调整大小；设置里的大小滑块会即时生效。右键可以选动作、切角度、随机跳窗、探头、隐藏和退出。
- 打盹时能看到胸腹轻微起伏。趴在窗口上时，尾巴会垂进窗口。久未互动时，糖豆会用气泡请求陪玩。
- 跳窗前先走到边缘、稍稍提速再起跳。已撤掉分件变形，恢复完整猫图动作，渲染跟随屏幕刷新。
- 淡黄色对话框会按文字长短调整大小，长句自动换行。
- 托盘双击打开设置，可选登录自启、游戏时收起和提醒。办公、浏览器与视频全屏继续显示。
- 找不到糖豆时，再次双击 EXE，或从托盘选「把糖豆叫回来」。

跳窗需要附近有留出头顶空间的窗口；探头需要先站在窗口上。

已开启自启时，从新目录运行一次会自动更新启动位置。
