# 糖豆 Jellybean 0.1

Windows 11，x64。完整解压后双击 **Jellybean.exe**，保留旁边的文件和 Assets 文件夹。

- 单击摸摸，双击开启逗猫棒；再双击或按 Esc 结束。
- 拖到窗口顶边附近松手，糖豆会停在窗口上。窗口移动时跟随，关闭或最小化后落下。
- 滚轮调整大小。右键糖豆或托盘图标，可以选动作、切换角度、跳窗、探头、隐藏和退出。
- 托盘双击打开设置，里面可选登录自启、全屏收起和提醒。默认安静、不自启、不开提醒。
- 找不到糖豆时，再次双击 EXE，或从托盘选「把糖豆叫回来」。

跳窗需要附近有留出头顶空间的窗口；探头需要先站在窗口上。

搬动程序目录后，如开启过自启，在设置里关掉再打开即可更新路径。
