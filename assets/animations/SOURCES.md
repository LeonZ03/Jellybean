# 首版补充动画

原始定稿位于 `assets/character/`，本次未覆盖。已有小样位于 `demo/`。

以下三个透明 PNG 使用内置 ImageGen 生成，参考定稿及已确认的小样，保持同一只糖豆和 H 形粉色背带。向右动作单独生成，保留该侧插扣；未直接翻转左侧素材。

| 文件 | 生成提示要点 |
| --- | --- |
| walk-right.png | 1536×1024，3×2 六帧，严格右侧面，交替迈步；细尾巴、细长耳朵、委屈眼神；背带胸圈紧邻前腿后侧，插扣在侧面；透明背景，无光晕与阴影。 |
| stretch.png | 相同网格，左侧面「站立→前爪前伸→压胸抬臀→保持→收回→站立」，保持角色比例与背带结构。 |
| pounce-right.png | 相同网格，右侧面「盯住→伏低→蓄力→腾空→前爪落地→伏稳」，参考已有左侧扑跳和定稿右侧背带。 |

`tools/AssetPack` 负责清除几乎不可见的背景 alpha（小于 8/255）、按落脚点对齐并打包为 192×176 的运行帧；成品在 `src/Jellybean/Assets/`。运行时不调用图像模型。
