# v0.2 动作素材

使用内置 ImageGen，以原定稿和小样为参考制作；原定稿保留在 `assets/character/`。

统一提示：同一只淡橘虎斑糖豆，健康而更瘦的身形、细长耳朵、委屈的琥珀眼神、细尾巴；保留粉色 H 背带、背部 D 环及侧面插扣。各帧同一体型、镜头和配色，透明背景，无光晕、阴影或文字。

| 文件 | 动作提示 |
| --- | --- |
| turnaround.png | 原六视图保持角度与站姿，身体约瘦一成，耳朵窄而更长，抬起眼睛内侧、外眼角轻垂。 |
| walk-left/right.png | 每方向 4×3 十二帧完整步态，固定躯干位置，长腿交替摆动、落脚；左右分别绘制，保留正确背带侧扣。右侧另做背景提取，保留动作与颜色。 |
| pounce-left/right.png | 3×2 六帧：站立、半蹲、伏低、腾空、屈腿着地、恢复站立。 |
| pet.png | 六帧正面坐姿：委屈地看人、抬头、闭眼、轻歪头、睁开、回原姿。 |
| doze.png | 站立、屈腿、收爪、趴好、闭眼、睡着；头和身体尺寸随姿势保持。 |
| perch.png | 背侧坐姿的吸气、耳动、回头和细尾巴轻卷。 |
| stretch.png | 站立、前爪前伸、压胸、完整伸展、起身、回原站姿。 |
| window-rest.png | 站立到窗沿趴卧，尾巴垂到支撑线以下并轻摆，不画窗口本身。 |

运行图集由 `tools/AssetPack` 统一落脚点和比例；站姿参考高度 124 像素、坐姿参考高度 112 像素。每个动作整组使用固定比例，躺下和伸展保留真实姿势变化。步幅由落地前爪的位移估算，左右分别写入动画清单。

提取帧时保留格子外 24 像素，并按主体连通区域分离邻帧，避免越过格线的尾巴和爪子被切断或混入下一帧。
