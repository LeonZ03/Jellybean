# 糖豆新增动作候选

表内 14 项已在 v0.6.0 接入。右键糖豆，打开「看看新动作」可以逐项试播。

| 动作 | 什么时候出现 | 看起来怎样 |
| --- | --- | --- |
| **转耳再回头** | 站着或坐着时偶尔 | 一边耳朵先转，头和视线晚半拍跟过去，再慢慢转回来。 |
| **闻一闻** | 鼠标在鼻尖附近停一下 | 脖子稍前伸，鼻尖动两下，闻完才收回。 |
| **换脚站** | 原地待了一会儿 | 重心轻轻偏向一边，另一只前爪抬一下，再换个落点。 |
| **舔爪洗脸** | 站累了，随坐下出现 | 低头舔前爪两三下，用爪背抹过脸颊和耳根。 |
| **打哈欠** | 睡前或刚醒 | 眼睛眯起来，嘴慢慢张开，合上后停半拍。 |
| **睡梦抽动** | 偶尔出现在熟睡中 | 保持呼吸，耳尖和一只前爪轻颤一下。 |
| **侧躺换边** | 趴了一会儿 | 肩先放下来，身体顺势侧倒，尾巴最后贴下。 |
| **蜷成一团** | 夜里或久未互动 | 收起前爪，把鼻尖埋进胸口，尾巴绕过后脚。 |
| **窗沿试探** | 走到陌生窗沿 | 身体停住，先探头看，再伸一只前爪试一下。 |
| **缩回去再偷看** | 窗沿探头时鼠标靠近 | 先缩下去，只露耳朵，隔半拍再露出眼睛。 |
| **伸一只爪够玩具** | 逗猫棒快碰到鼻尖 | 身体伏住，只用一只前爪快速扫一下，错过就收爪。 |
| **扑空后回头** | 逗猫棒从身旁甩开 | 刹住，耳朵先转向玩具，头再跟上，重新瞄准。 |
| **顶一下手** | 被摸时鼠标还在头边 | 眯着眼把额头轻轻迎过去，顺势蹭一下。 |
| **踩奶** | 放松地趴着时偶尔 | 两只前爪交替按下，肩背有很轻的起伏。 |
