# 糖豆侧面走路小样

[行走预览](walk.mp4) · [透明帧图集](atlas.png)

用现有糖豆侧身画稿绘制完整帧。四脚的着地顺序和抬脚轨迹先固定，再沿同一轨迹绘制过渡。胸背轻微起伏，移动速度按每周期 76 像素计算。按真猫实拍核对落脚，遮挡处参考已收录的完整动作曲线。[真猫慢放](https://doi.org/10.1371/journal.pone.0003808.s002) · [动作参考](../motion-reference/SOURCES.md)

单轮 64 帧，60 帧/秒。透明图集从左到右、从上到下排列，每格 224 × 164 像素。预览连续走五轮，便于看接缝和支撑脚。腿部笔触和上身原画仍有差异，供小样评审。

Wan VACE 本地试片保留了导引里的尾巴方向与地面杂影，脚部失去清晰轮廓。此次预览采用按脚掌轨迹绘制的版本。
