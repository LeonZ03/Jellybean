# 糖豆实拍逐帧行走小样

[实际向前走](walk.mp4) · [16 张姿势图](poses.png) · [透明帧图集](atlas.png)

取真猫侧面慢放里的连续姿势，逐张生成糖豆的整猫图。按定稿保留细长耳朵、眼神、橘色条纹和粉色 H 背带。帧间使用同一缩放比例和落地基准，合成时按四段支撑脚的实际位移选定每轮前进距离。

左侧小样每轮 0.8 秒，共 16 张独立画面，每张播放 0.05 秒。透明图集按从左到右、从上到下排列，每格 224 × 164 像素。第 2 到第 3 张的前脚衔接仍偏急，供本轮看动作时重点确认。

- 主要步态参考取约 4.67–7.30 秒的侧面慢放，逐格看前后脚交替支撑。[Bishop 等人的直立步行实拍 S2](https://doi.org/10.1371/journal.pone.0003808.s002)
- 补看约 5.5–7.6 秒的前脚前摆、后腿收回和肩背变化。[Bayram Yalçın 的橘猫过街慢放](https://www.pexels.com/video/an-orange-cat-crossing-the-street-in-slow-motion-15386749/)
- 对照重心更低时的走法。[Bishop 等人的低姿步行实拍 S1](https://doi.org/10.1371/journal.pone.0003808.s001)
